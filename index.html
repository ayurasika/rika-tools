気温と地温の1日の変化読取
晴れの日とくもりの日で気温変化はどう違う？
最高気温地温雲の働き
攻略ポイント
・太陽高度の最高＝正午（12時）
・地温の最高＝午後1時ごろ（太陽の1時間後）
・気温の最高＝午後2時ごろ（地温の1時間後）
・気温は地面から伝わる熱であたたまるので、太陽→地面→空気の順で遅れる

晴れの日：気温の変化が大きい（昼は高温、夜は低温）
くもりの日：気温の変化が小さい
・昼：雲が太陽光をさえぎるので気温が上がりにくい
・夜：雲が地面の熱を宇宙へ逃がさないので気温が下がりにくい
2
飽和水蒸気量と湿度計算
湿度公式と表の読み方
飽和水蒸気量湿度露点結露
攻略ポイント ★最頻出★
飽和水蒸気量＝1m³の空気がふくめる水蒸気の限界量（g/m³）
気温が高いほど飽和水蒸気量は大きい

湿度の公式（絶対暗記）
湿度(%)＝（実際の水蒸気量 ÷ その気温の飽和水蒸気量）× 100

露点＝湿度100%になる気温（＝水てきが出始める気温）
結露量 ＝ 実際の水蒸気量 − 下げた温度の飽和水蒸気量

気温↑ → 飽和水蒸気量↑ → 湿度↓
気温↓ → 飽和水蒸気量↓ → 湿度↑ → 露点で結露
3
乾湿球湿度計読取
湿球はなぜ乾球より温度が低い？
乾球湿球気化熱湿度表
攻略ポイント
・乾球＝そのままの気温
・湿球＝ガーゼが水にぬれている。水が蒸発するときまわりから熱をうばうので、乾球より温度が低くなる

湿度が低い（乾燥）→ 蒸発が多い → 差が大きい
湿度が高い（多湿）→ 蒸発が少ない → 差が小さい
湿度100% → 乾球＝湿球（差0）

湿度表の読み方：縦＝乾球温度／横＝差（乾球−湿球）
例：乾球21℃、湿球18℃ → 差3℃ → 湿度73%

フェーン現象計算
山を越えると風下は高温で乾燥する
100m＝1℃0.5℃乾燥
攻略ポイント ★計算問題頻出★
基本ルール
・上昇100m＝1℃下がる（雲ができる前）
・雲ができてからは100mで0.5℃しか下がらない（水蒸気が水になるとき熱を出すから）
・下降100m＝1℃上がる（常に）

手順
①風上のふもと→雲の高さ：100mで1℃下がる
②雲の高さ→山頂：100mで0.5℃下がる
③山頂→風下ふもと：100mで1℃上がる

結果：風下の温度＞風上の温度、乾燥

海風・陸風・なぎ暗記
昼と夜で風の向きが逆になる理由
海風陸風なぎ
攻略ポイント
基本原理：あたたまった空気が上昇 → そこへまわりの空気が流れ込む＝風
・陸はあたたまりやすく冷めやすい
・海はあたたまりにくく冷めにくい

昼（晴れた日）
陸＞海 → 陸の空気が上昇 → 海風（海→陸）

夜
海＞陸 → 海の空気が上昇 → 陸風（陸→海）

なぎ：朝と夕方、地面と海面の温度が等しい → 風がやむ（朝凪・夕凪）

海陸風の大規模版＝季節風
夏・南東冬・北西偏西風
攻略ポイント
夏の季節風＝南東の風（太平洋→日本→大陸）
大陸があたたまる→大陸上の空気が上昇→太平洋から南東の風
小笠原気団（暖・湿）を運ぶ

冬の季節風＝北西の風（シベリア→日本→太平洋）
太平洋側があたたかい→太平洋上の空気が上昇→大陸から北西の風
シベリア気団（冷・乾）を運ぶ

偏西風＝上空で1年を通して西から東へふく風
・天気が西から東へ変わる／台風を北東へ流す

4つの気団と気圧配置暗記
気団の性質は温度×湿度の2軸で覚える
シベリアオホーツク小笠原揚子江
攻略ポイント
4つの気団（温度×湿度）
・シベリア気団：冷・乾（北西／大陸）
・オホーツク海気団：冷・湿（北東／海）
・小笠原気団：暖・湿（南東／海）
・揚子江気団：暖・乾（南西／大陸）

気団の性質を決めるルール
・大陸の上でできる→乾いている／海の上でできる→湿っている
・北でできる→冷たい／南でできる→暖かい

四季の気圧配置
・春／秋：移動性高気圧と低気圧が交互（揚子江気団）
・梅雨：停滞前線（オホーツク vs 小笠原）
・夏：南高北低（小笠原強）
・冬：西高東低（シベリア強）

台風暗記
定義・進路・風向変化
17.2m/s反時計右が強風
攻略ポイント
定義：熱帯低気圧のうち最大風速が秒速17.2m以上／日本の南海上で発生

進路：小笠原気団のふちにそって北上→北上後、偏西風で北東に流される

風向の変化（北半球では反時計回りにふきこむ）
・台風が観測地点の東を通過：東→南→西
・台風が西を通過：東→北→西
・進行方向の右側＝台風風＋進む風が重なり強風

災害：大雨・洪水・暴風・高潮（※津波は地震による！ひっかけ）
